# Aurum Arts 🎨✨  

Aurum Arts is an online auction platform specialized in **artworks and paintings**, built with **Django**.  
The project features a **modern UI** with an **art gallery / auction house aesthetic**, making the experience elegant and user-friendly.

## 🚀 Features  

- **User Authentication**  
  - Register, login, and logout system.  
  - Each user has their own account to place and manage bids.  

- **Auction Listings**  
  - Create new auction listings for artworks.  
  - Add details such as title, description, starting bid, and image.  
  - Listings remain active until closed.  

- **Bidding System**  
  - Users can place bids higher than the current one.  
  - Auction winner is determined when a listing is closed.  

- **Watchlist**  
  - Add or remove artworks to a personalized watchlist.  
  - Easily keep track of favorite auctions.  

- **Comments Section**  
  - Users can comment on artwork listings.  
  - Encourages interaction between buyers and sellers.  

- **Categories**  
  - Browse artworks by category (e.g., Contemporary, Modern, Classical Art).  

- **Polished Interface**  
  - Clean, elegant design adapted to an **art gallery / auction house aesthetic**.  
  
---

## 🖥️ Tech Stack  

- **Backend:** Django (Python)  
- **Frontend:** HTML, CSS, Bootstrap (custom styling for elegance)  
- **Database:** SQLite (development)  
- **Authentication:** Django’s built-in auth system
